BAN DO SOURCE CODE - WEB / APP / BACKEND

Muc tieu cua file nay:
- Giup ban xac dinh nhanh: thay hoi sua chuc nang nao thi mo file nao truoc.
- Giup ban hoc source theo luong chay that, khong bi ngop boi qua nhieu file.
- Gom du 3 phan: Web, App, Backend.

====================================================================
PHAN 1 - TONG QUAN HE THONG
====================================================================

Cach nam repo nay nhanh va thuc dung nhat la hoc theo luong chay that, khong doc lan man.
Bo qua App/bin, App/obj, Backend/__pycache__, chi tap trung vao 3 khoi:

- Backend: API, auth, database, nghiep vu
- Web: giao dien quan tri / chu quan bang HTML + JS thuan
- App: ung dung MAUI cho nguoi dung cuoi

Luong tong quat:

Web/App -> goi endpoint Backend -> Backend xu ly nghiep vu + DB -> tra du lieu ve UI

File khoi dong quan trong:

- Backend/main.py
- Backend/app_factory.py
- App/MauiProgram.cs

PHAN 3 - BACKEND NAM O DAU
====================================================================

1. Backend/config.py
- Chua cau hinh he thong:
  DATABASE_URL, APP_SECRET, SESSION_COOKIE, WEB_DIR, UPLOAD_DIR, CORS_ORIGINS
- Neu thay hoi doi DB, doi cookie, doi upload, doi CORS, doi script toi thieu
  thi mo file nay truoc.

2. Backend/db.py
- Tao engine, session, Base
- Ham ensure_schema_columns() de bo sung cot cho DB cu
- Neu thay hoi sua cau truc cot ma he thong cu van phai chay duoc thi mo file nay.

3. Backend/models.py
- Dinh nghia bang:
  Role, User, Language, Category, Stall, StallTranslation, Review,
  ListeningLog, StallAudioAsset, StallUpdateRequest, AdminNotification,
  AdminNotificationRecipient, QrScanLog, LocationLog
- Neu thay hoi bang nao luu du lieu gi, quan he giua bang nao voi bang nao,
  thi mo file nay.

4. Backend/schemas.py
- Chua request model:
  LoginRequest, CreateOwnerRequest, UpdateUserRequest,
  CreateAdminNotificationRequest, UserLocation, SearchRequest, RatingRequest
- Neu thay hoi API nhan body gi thi mo file nay.

====================================================================
PHAN 4 - MAP ROUTER BACKEND
====================================================================

1. Backend/routers/web.py
Chiu trach nhiem:
- Tra HTML cho web
- Dang nhap / dang xuat
- Kiem tra phien
- Danh muc

Endpoint chinh:
- GET /login
- GET /owner
- GET /superadmin
- POST /auth/login
- POST /auth/logout
- GET /auth/me
- GET /categories

Neu thay hoi:
- Dang nhap nam o dau?
- Cookie session nam o dau?
- Tai sao owner vao trang nay, admin vao trang kia?
=> Mo routers/web.py truoc.

2. Backend/routers/public.py
Chiu trach nhiem:
- nearby stalls
- search
- stalls map
- stall detail
- reviews
- QR resolve
- logs listening
- logs location
- audio

Endpoint chinh:
- POST /nearby
- GET /sync/version
- POST /search
- GET /stalls/map
- GET /stalls/{stall_id}
- POST /stalls/{stall_id}/reviews
- GET /qr/resolve
- POST /logs/listening
- POST /logs/location
- GET /audio/stalls/{stall_id}

Neu thay hoi:
- App lay danh sach quan gan day o dau?
- Search tinh diem kieu gi?
- Review sao cap nhat o dau?
- QR scan xu ly o dau?
- Audio tao o dau?
=> Mo routers/public.py truoc, roi lan sang services.py.

3. Backend/routers/owner.py
Chiu trach nhiem:
- Du lieu stall cua chu quan
- Dashboard chu quan
- Thong bao / inbox
- Gui yeu cau cap nhat stall
- Tao stall lan dau

Endpoint quan trong:
- GET /owner/stall
- GET /owner/dashboard
- GET /owner/notifications
- POST /owner/stall
- POST /owner/stall-update-request

Neu thay hoi:
- Chu quan sua thong tin thi sua that hay cho duyet?
- Dashboard owner lay so lieu tu dau?
- Owner co thong bao o dau?
=> Mo routers/owner.py.

4. Backend/routers/admin.py
Chiu trach nhiem:
- Dashboard superadmin
- Danh sach owner
- Tao owner
- Quan ly user
- Duyet / tu choi request
- Gui thong bao admin

Endpoint quan trong:
- GET /admin/dashboard
- GET /admin/users
- POST /admin/users
- GET /admin/update-requests
- POST /admin/update-requests/{id}/approve
- POST /admin/update-requests/{id}/reject

Neu thay hoi:
- Admin duyet quan o dau?
- Admin tao owner o dau?
- Dashboard heatmap, top stalls, active users nam o dau?
=> Mo routers/admin.py.

PHAN 5 - FILE NGHIEP VU TRUNG TAM
====================================================================

Backend/services.py la file nghiep vu trung tam.

Can nho cac nhom ham:

1. Auth
- hash_password()
- verify_password()
- create_session_cookie()
- get_current_user_from_request()
- require_auth_page()
- require_role()

2. Validate stall
- require_minimum_stall_script()
- require_specialties()
- require_poi_radius()
- build_opening_hours()

3. Translation va noi dung
- upsert_stall_translations()

4. Serialize du lieu tra ve UI
- serialize_stall_card()

5. Search, rating, QR, audio
- resolve_stall_qr_code()
- refresh_stall_rating_summary()
- compute_search_score()
- generate_audio_bytes()
- get_content_sync_version()

6. Seed du lieu
- ensure_seed_data()
- ensure_default_web_users()

Mau nho:
- Router quyet dinh mo cong nao
- services.py quyet dinh xu ly that ra sao
